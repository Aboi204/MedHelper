# 🩺 MedHelper | منصة الشرح الطبي الأكاديمي الذكي

> **نظام ذكي لتدريب نماذج الذكاء الاصطناعي على منطق وتكنيك كبار الأساتذة الأكاديميين (نموذج د. عبد المتعال فودة) لتقديم شرح حقيقي عميق ومبسط للمحاضرات الطبية.**

---

## 🌟 فكرة المشروع (Core Concept)

الذكاء الاصطناعي التقليدي يكتفي بتلخيص السلايدات أو إعادة صياغتها، بينما يحتاج طالب الطب إلى **"فهم حقيقي"** كما يشرح كبار الأساتذة المحنكون.

يقوم **MedHelper** بـ:
1. **استخراج وهندسة أسلوب التدريس عكسياً (Reverse-Engineering Pedagogy):** تفكيك تفريغ محاضرات كبار الأساتذة عبر **11 ركيزة بيداغوجية** لاستخراج منطق الفهم والتسلسل الذهني.
2. **شرح المحاضرات الطبية (Deep Lecture Explainer):** قراءة ملفات السلايدات والـ PDF وتوليد شرح متعمق يؤصل للفسيولوجيا الطبيعية، ويشرح الميكانيزمات، ويستنتج الآثار الجانبية وموانع الاستعمال من صميم الآلية، مع فخاخ الامتحانات (Clinical Pearls).
3. **النطق الصوتي الطبي الأكاديمي (AI Voice Narration):** تحويل الشرح إلى صوت بشري طبيعي بالكامل عبر تقنية عصبية مجانية.
4. **صفر تكلفة مالية (100% Free):** كل أداة ونموذج ومكتبة في هذا النظام مجانية ومفتوحة المصدر بالكامل.

---

## 🏗️ الركائز الـ 11 لتفكيك منطق الشرح

1. **نقطة البداية (<bdi>The Hook</bdi>):** التأصيل الفسيولوجي والبدء من الأساس الطبيعي.
2. **ترتيب بناء الفكرة (<bdi>Cognitive Flow</bdi>):** فسيولوجيا ← باثولوجيا ← ميكانيزم الدواء ← استنتاج الأعراض والفوائد.
3. **طريقة التقسيم والتشجير (<bdi>Taxonomy & Chunking</bdi>):** عائلات هرمية واضحة.
4. **نوع الأمثلة والتشبيهات (<bdi>Analogies</bdi>):** تشبيهات ميكانيكية وسريرية واقعية.
5. **الربط التراكمي (<bdi>Scaffolding</bdi>):** ربط المعلومة بما سبق دراسته.
6. **استباق اللبس وفخاخ الامتحانات (<bdi>Differential Logic & Pitfalls</bdi>).**
7. **توقيت الربط بالتطبيق السريري (<bdi>Clinical Relevance</bdi>).**
8. **تسلسل طرح المصطلحات (<bdi>Terminology Sequence</bdi>).**
9. **التلخيص وتثبيت الذاكرة (<bdi>Retention & Wrap-up</bdi>).**
10. **الأسئلة السقراطية والوقفات الذهنية (<bdi>Socratic Probing</bdi>).**
11. **البناء الهيكلي المرئي (<bdi>Mental Schematics & Diagrams</bdi>).**

## 🚀 طريقة التشغيل (Quick Start)

### 1. المتطلبات:
* <bdi>Python 3.10+</bdi>
* مفتاح مجاني من <bdi>[Google AI Studio](https://aistudio.google.com/)</bdi>

### 2. التثبيت:
```bash
git clone https://github.com/YourUsername/MedHelper.git
cd MedHelper
pip install -r requirements.txt
```

### 3. التشغيل بضغطة زر:
* على نظام ويندوز: اضغط مرتين على ملف `run_medhelper.bat`.
* أو عبر سطر الأوامر:
```bash
streamlit run app.py
```
